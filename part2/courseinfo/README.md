# Full Stack Open – Part 2: Course Information

This project contains solutions for the **Course Information** exercises in Part 2 of the Full Stack Open course.

The application renders multiple courses, each with its parts and total number of exercises.

It demonstrates:

* Component composition and reuse
* Passing structured data via props
* Rendering dynamic lists with `map`
* Calculating derived data (totals)
* Splitting React components into separate modules

## Run the project

```bash
npm install
npm run dev
```

Built with React and Vite for learning purposes.
