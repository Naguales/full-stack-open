# Full Stack Open – Part 1: Anecdotes

This project contains the **Anecdotes** exercises from Part 1 of the Full Stack Open course.

The app displays random software engineering anecdotes, allows users to vote for them, and shows the anecdote with the highest number of votes.

It demonstrates:

* Managing state with React hooks
* Handling events and updating state immutably
* Working with arrays in state
* Deriving computed data (top-voted anecdote)

## Run the project

```bash
npm install
npm run dev
```

Built with React and Vite for learning purposes.
