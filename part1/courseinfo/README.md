# Full Stack Open – Part 1: React Basics

This project contains solutions for **Part 1** of the Full Stack Open course, including the **Courseinfo** exercise.

The app demonstrates:
* Building and composing React components
* Passing data between components using props
* Structuring an app with `Header`, `Content`, `Part`, and `Total` components

## Run the project
```bash
npm install
npm run dev
```

Built with React and Vite for learning purposes.
