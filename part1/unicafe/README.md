# Full Stack Open – Part 1: Unicafe

This project contains solutions for the **Unicafe** exercise in Part 1 of the Full Stack Open course.

The app collects user feedback and displays statistics about it.

It demonstrates:

* Managing component state with React hooks
* Handling events (button clicks)
* Conditional rendering
* Deriving statistics from application state
* Structuring the UI with reusable components

## Run the project

```bash
npm install
npm run dev
```

Built with React and Vite for learning purposes.
